# MediaForge AI

MediaForge AI is a professional Windows desktop application combining multi-platform media downloading, transcription, AI translation, subtitle styling, stem separation, and expressive voice dubbing.

## Target Platform
- Windows 10 & Windows 11 64-bit
- Python 3.11+
- PySide6 6.7+

## Development Setup
```bash
python -m pip install -r requirements.txt
pytest tests/unit/
```
